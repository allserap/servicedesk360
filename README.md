# ServiceDesk 360

## Descripción
Aplicación web desarrollada con JSP y Servlets para gestionar solicitudes de soporte técnico. El proyecto forma parte de la guía práctica de la asignatura de Desarrollo de Aplicaciones Multiplataforma.

## Tecnologías utilizadas

- Java JDK 11 o superior
- JSP y Servlets
- Apache Tomcat 9
- Apache Maven
- Apache NetBeans

## Requisitos

1. Tener instalado Java JDK 11 o superior.
2. Tener instalado Apache Tomcat 9.
3. Registrar Tomcat en Apache NetBeans.
4. Tener Maven configurado (o utilizar el integrado de NetBeans).
5. Verificar que el puerto configurado para Tomcat (8090) esté disponible.

## Instalación

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/allserap/servicedesk360.git
   ```

2. Abrir el proyecto en Apache NetBeans.

3. Verificar que el servidor Apache Tomcat esté asociado al proyecto.

4. Ejecutar **Clean and Build**.

5. Ejecutar el proyecto con **Run Project**.

## Acceso

Una vez desplegado, abrir en el navegador:

```
http://localhost:8090/ServiceDesk360/
```

> Si el Context Path fue modificado en las propiedades del proyecto, la URL cambiará de acuerdo con dicho nombre.
